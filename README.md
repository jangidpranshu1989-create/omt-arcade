47 Interactive Experiments — Desi Games, Puzzles, Creative Tools and Science Simulations

A browser-based arcade inspired by the spirit of interactive web experiments.

🎮 Game Categories

- 🇮🇳 Desi Originals — Hand Cricket, KBC Quiz, Antakshari, IPL Auction and more.
- 🔬 Science & Space — 3D Ocean, Space Explorer, Asteroid Simulator and Earth Science.
- 🧩 Puzzles — 2048, Snake, Memory Match, Tic Tac Toe and more.
- 🎨 Creative — Rangoli, Mehndi, Meme Maker, Pixel Painter and Color Palette.
- 💰 Life Simulations — Startup Simulator, Tax Calculator, Street Food Tycoon and more.

The catalogue describes planned or documented games. Actual availability depends on the implementation.

🛠️ Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Three.js for 3D scenes
- Leaflet for interactive maps
- Browser localStorage where used

External libraries may require an internet connection.

🚀 Run Locally

Open the project folder in Termux:

"cd ~/omt-arcade"

Start a local server:

"python -m http.server 8000"

Open http://localhost:8000 in your browser.

🌐 Deployment

For a static deployment, when no build step is required:

- Publish directory: "."
- Build command: Leave blank
- Entry point: "index.html"

Verify asset paths, external dependencies, and mobile layout before publishing.
